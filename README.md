# CS-Cart GDPR Enhanced (Velobike.by)

Модуль расширяет и исправляет стандартный модуль GDPR (Klaro) в CS-Cart.
Создан специально для соблюдения строгих норм сбора cookie и улучшения визуальной составляющей.

## Что делает модуль:
1. **Исправляет баг режима Explicit (opt-in)**. В стандартном CS-Cart ползунки оставались включенными по умолчанию даже при явном согласии. Модуль принудительно отключает их (`default = false`), как того требует закон. При этом оригинальные файлы ядра не затрагиваются (используется переопределение схемы).
2. **Добавляет маркетинговые сервисы**. В баннер пробрасываются сторонние счетчики (Google Analytics 4, Google Ads, Яндекс.Метрика, Meta Pixel).
3. **Обновляет скрипт Klaro**. Заменяет устаревший `klaro.js` (v0.7.18) на свежий (v0.7.22), в котором исправлены баги рендеринга (особенно в Safari и на мобильных устройствах).
4. **Улучшает дизайн (UI/UX)**. 
   - Полностью переписаны стили под фирменные цвета Velobike (темно-синий `#18233e` и желтый `#ffd600`).
   - Настроена мобильная версия (кнопки выстроены в удобную колонку, «Принять» на первом месте).
   - Исправлена читаемость текста в темной теме ОС (Dark Mode).
   - Блокируется прокрутка заднего фона страницы (body) при открытом окне настроек (используется `:has()` селектор).
   - Устранен конфликт галочек-переключателей с темой UniTheme2.

## Установка

Модуль работает по принципу *Drop-in replacement* (переопределение через хуки). Он не затирает системные файлы CS-Cart, благодаря чему является **Update-safe** (безопасным при обновлениях).

1. Скопируйте содержимое папок `app`, `js` и `var` в корень вашего сайта.
2. Перейдите в админ-панель CS-Cart -> Модули -> Управление модулями.
3. Найдите модуль **"GDPR Enhanced"** и нажмите Установить / Включить.
4. Очистите кэш (Администрирование -> Очистить кэш).

> **Важно для сторонних счетчиков:**
> Чтобы Klaro блокировал ваши счетчики до получения согласия, в их коде нужно изменить тег `<script>` следующим образом:
> ```html
> <script type="text/plain" data-type="application/javascript" data-name="google-analytics">
>   // Ваш код GA4
> </script>
> ```
> Доступные `data-name`: `google-analytics`, `google-ads`, `yandex-metrika`, `facebook-pixel`.

## Структура модуля
- `app/addons/gdpr_enhanced/` - конфигурация модуля и переопределение схемы (`klaro_config.post.php`).
- `js/addons/gdpr_enhanced/lib/` - обновленная библиотека `klaro.js`.
- `var/themes_repository/responsive/css/addons/gdpr_enhanced/` - обновленный `klaro.css` и кастомные стили `velobike_gdpr.less`.
- `var/themes_repository/responsive/templates/addons/gdpr_enhanced/overrides/` - шаблоны-хуки, которые подменяют загрузку старого скрипта на новый.
